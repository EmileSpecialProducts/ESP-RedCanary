ESP-RedCanary

Devices ESP-32 (S3/S2/C3/C5/C6)

This will program the ESP-RedCanary software to the ESP-32 (S3/S2/C3/C5/C6) device.
After programming you can connect to the AP Wifi name is ESP-RedCanary and set the Wifi SSID and Password.
After reboot you can connect to the device. ( sometimes you will need a second reboot )
The ESP-C5 is not supported, in the esp-web-tools 10.2.1
