# ESP-RedCanary

This is the ESP-RedCanary example for esp-arduino ESP32/S2/S3/C3/C6 Not yet supported ESP32-C2/C5/C61/P4.  
ESP-8266/ESP12E is not supported
And only the ESP32S3 is used for development  

It still will need a lot of work so it is "Under-Construction"  

It Setup from a Accesspoint, LittleFS storage, . 

This is based on Arduino Release v3.3.7 from pioarduino [(p)eople (i)nitiated (o)ptimized (arduino)](https://github.com/pioarduino/platform-espressif32) 

[//]: # To test this software you can use the [Web Programming portal](https://emilespecialproducts.github.io/ESP-RedCanary/upload.html) to Program your ESP-Chip, No development software needed.  

After programming you will need to setup the Wifi connection this is done by connection to the ESP Access Point (ESP-RedCanary)
And set up your Wifi and Canary Tokens.


You can find a link the to [Youtube](https://youtu.be/SGOuzqJMnVM) for the SPIFFS version
